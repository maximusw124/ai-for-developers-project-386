# S02: Админка: профиль владельца и типы встреч (создание/редактирование)

**What to build:** Админка `/admin` без авторизации с постоянным предупреждением о демо-режиме. Секция «Профиль» позволяет читать и менять имя владельца. Секция «Типы встреч» показывает активные и архивные типы, позволяет создать и отредактировать тип в inline-форме. Созданный или изменённый тип сразу виден на публичной странице записи. Валидация названия и длительности возвращает понятные ошибки у полей.

**Blocked by:** S01

**Status:** ready-for-agent

- [ ] `GET/PATCH /admin/owner`; пустое имя после trim → `422`; имя сохраняется и показывается на публичной стороне
- [ ] `GET/POST/PATCH /admin/meeting-types` и `GET /admin/meeting-types/{id}`; список активных выше архивных, внутри — по возрастанию id
- [ ] Inline-форма: название 1..100 (trim), описание 0..2000, длительность 15..540 и кратна 15; дубликаты названий разрешены
- [ ] Ошибки: 14/15/45/540/541 и нецелая длительность; пустое имя; серверная ошибка в alert; success через live-region
- [ ] Публичный `/book` отражает активные типы сразу после сохранения; доступность и предстоящие ещё не входят в срез
- [ ] API- и компонентные тесты; видимые `<label>`, `aria-invalid`, `aria-describedby`, управление фокусом
