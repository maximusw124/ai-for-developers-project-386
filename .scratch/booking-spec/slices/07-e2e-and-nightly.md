# S07: Полный Playwright e2e и ночные проверки

**What to build:** Сквозной браузерный тест доказывает весь сценарий на настоящем стеке: владелец создаёт тип встречи в админке, гость видит его на странице записи, выбирает дату и слот и бронирует, после чего владелец видит встречу в предстоящих. Сервер поднимается с настоящей SQLite и фиксированными часами, фронтенд — через Vite на эфемерных портах. Ночной workflow добавляет браузерную и часовую матрицу и политику flaky.

**Blocked by:** S05, S06

**Status:** ready-for-agent

- [ ] E2E: владелец создаёт тип → гость видит 14 дней, выбирает слот, отправляет форму → экран подтверждения → владелец видит встречу
- [ ] Реальный Fastify + временный файл SQLite + Vite на эфемерных портах; фиксированные часы через тестовую конфигурацию
- [ ] Сценарий проверяет сообщение о часовом поясе и отсутствии письма
- [ ] Nightly workflow: Firefox/WebKit и прогон с не-московской `TZ`; результаты не блокируют PR
