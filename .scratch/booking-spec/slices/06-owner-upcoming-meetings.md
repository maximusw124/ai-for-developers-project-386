# S06: Предстоящие встречи владельца

**What to build:** В админке появляется секция «Предстоящие встречи»: владелец видит все встречи, которые ещё не закончились, включая идущую сейчас. Список отсортирован по началу и сгруппирован по московской дате на клиенте; в карточке — интервал, тип, имя гостя, email-ссылка, комментарий и время создания. Архивный тип и идущая встреча отмечены бейджами. Есть ручное обновление, скелетоны, пустое состояние и ошибка с повтором.

**Blocked by:** S05

**Status:** ready-for-agent

- [ ] `GET /admin/bookings/upcoming` возвращает встречи с `end > now`, отсортированные по `start` возрастанию
- [ ] Поля: интервал, тип, имя гостя, email, комментарий, время создания; email — доступная ссылка `mailto:`
- [ ] Секция админки группирует по московской дате; бейджи «Сейчас» и «Тип в архиве»; часовой пояс указан текстом
- [ ] Кнопка «Обновить» без polling; скелетоны при загрузке; ошибка — alert с повтором; пустое состояние по тикету 07
- [ ] Секции загружаются независимо: ошибка встреч не скрывает профиль и типы
- [ ] API- и компонентные тесты: идущая/будущая/прошедшая, сортировка, группировка, архивный тип, пусто, обновление, ошибка
