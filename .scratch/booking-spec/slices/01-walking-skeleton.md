# S01: Walking skeleton: контракт, генерация, БД-каркас, публичный список, проверки и e2e-смоук

**What to build:** Тонкий сквозной путь от TypeSpec до браузера. Контракт в отдельном workspace эмитит OpenAPI 3.1.0, из него генерируются клиентский SDK/типы и серверные типы. Бэкенд поднимается под `/api`, применяет миграции с владельцем и таблицей типов встреч и отдаёт пустой публичный список из SQLite. Страница записи читает список через сгенерированный SDK и показывает пустое состояние. Общая команда проверок включает контракт, линтер, типы, сборку и тесты; отдельная команда поднимает Playwright-смоук против настоящего сервера.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] TypeSpec-контракт эмитит OpenAPI 3.1.0 и две генерации (SDK/типы для фронтенда, типы для бэкенда); drift-check падает при ручной правке OpenAPI
- [ ] Миграции создают `owner` и `meeting_types`, идемпотентно сидят одного владельца; тестовая БД изолирована
- [ ] `GET /api/meeting-types` возвращает `200 []` из SQLite; API-тест через `app.inject`
- [ ] `/book` рендерит пустое состояние по данным SDK; компонентный тест
- [ ] `mise run check` зелёный на свежем клоне (контракт/drift, Biome, типы, сборка, unit/API/UI)
- [ ] `mise run e2e` поднимает реальный сервер и загружает `/book`
