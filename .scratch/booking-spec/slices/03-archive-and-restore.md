# S03: Жизненный цикл типа: архив и восстановление

**What to build:** Владелец архивирует тип встречи вместо удаления и при необходимости восстанавливает его. Архивирование скрывает тип из публичной записи, делает прямую ссылку и доступность недоступными и блокирует новые бронирования, но сохраняет существующие встречи. Архивный тип нельзя редактировать до восстановления. Подтверждение архивации — inline, без модального окна.

**Blocked by:** S02

**Status:** ready-for-agent

- [ ] `POST /admin/meeting-types/{id}/archive` и `/restore`; список админки группирует активные выше архивных
- [ ] Архивный тип исчезает из публичного списка; `/book/:id`, доступность и создание брони для него → `404`
- [ ] Существующие бронирования архивного типа сохраняются; архивный тип read-only
- [ ] Inline-подтверждение архивации с предупреждением «Тип исчезнет из записи, существующие встречи сохранятся»; фокус переходит на подтверждение и возвращается при отмене
- [ ] Восстановление снимает архивность и возвращает тип в публичную запись
- [ ] API- и компонентные тесты; статус архивности передаётся не только цветом; live-region для результата
