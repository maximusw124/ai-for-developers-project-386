# S04: Доступность: 14-дневное окно и слоты

**What to build:** Гость выбирает тип встречи, видит ленту из 14 календарных дней по Москве и сетку свободных слотов на выбранный день. Слоты строятся по рабочим часам Пн–Пт 09:00–18:00 с шагом 30 минут, только в будущем и с учётом всех существующих бронирований. Пустые и выходные дни остаются в ленте с пустым списком. Доступность запрашивается одним запросом на всё окно.

**Blocked by:** S01, S02, S03

**Status:** ready-for-agent

- [ ] Домен построения слотов на Luxon с инъекцией `now`: 14 дней `0..13`, Пн–Пт, сетка 09:00 + 30 минут, `start > now`, `start + duration <= 18:00`
- [ ] `GET /meeting-types/{id}/availability` возвращает тип и ровно 14 дней; `date` — `YYYY-MM-DD` по Москве, `start`/`end` — ISO UTC с `Z`
- [ ] Выходные и пустые дни присутствуют с пустым списком; прошедшие слоты сегодня отброшены; последние старты для 30/45/60/540 корректны
- [ ] Занятость глобальна для всех типов; примыкание разрешено; архивный и неизвестный тип → `404`
- [ ] UI: лента дат и сетка слотов, пустые состояния, первый день со слотами выбран по умолчанию, время форматируется через `Intl` с `Europe/Moscow`
- [ ] Unit-тесты с фиксированным `now`; API- и компонентные тесты; прогон с `TZ=UTC` и не-московской зоной
