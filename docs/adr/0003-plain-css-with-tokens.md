# Обычный CSS с токенами вместо Tailwind или UI-библиотеки

Для главной и заглушки записи используется обычный CSS с CSS-переменными в `src/styles/tokens.css`. Проект небольшой, новых runtime-зависимостей не требуется, а токены переиспользуются на странице записи. Альтернативы — Tailwind или готовая UI-библиотека — дали бы больше готовых компонентов, но добавили бы конфигурацию и ограничения ради одной страницы.

## Consequences

Классы именуются вручную по BEM-подобной схеме; при росте интерфейса стоит следить за отсутствием конфликтов имён.
