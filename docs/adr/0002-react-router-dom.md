# SPA-роутинг через react-router-dom

Маршруты `/` и `/book` реализуются через `react-router-dom`, а не через условный рендер в `App`. Страница записи станет отдельным полноценным экраном на следующем шаге, поэтому реальные URL и маршрутизация нужны уже сейчас. Альтернатива без роутера потребовала бы переделки навигации и тестов.

## Consequences

На статическом хостинге потребуется SPA-fallback на `index.html` для прямых переходов на `/book`.
