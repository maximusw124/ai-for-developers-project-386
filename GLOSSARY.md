# Календарь звонков

Учебный сервис онлайн-записи на встречи: владелец публикует типы встреч и расписание, гость выбирает свободный слот и бронирует звонок.

## Language

**Владелец**:
Пользователь, который настраивает типы встреч и расписание и принимает бронирования.
_Avoid_: организатор, хост, пользователь

**Гость**:
Человек, который переходит по публичной ссылке и бронирует встречу.
_Avoid_: клиент, посетитель, пользователь

**Тип встречи**:
Шаблон встречи с названием, длительностью и местом проведения, на который гость может записаться.
_Avoid_: событие, услуга, звонок

**Встреча**:
Запланированный звонок между владельцем и гостем.
_Avoid_: событие, ивент

**Слот**:
Конкретный промежуток времени, доступный для бронирования.
_Avoid_: окно, таймслот, время

**Расписание**:
Набор правил владельца, определяющий доступные для бронирования слоты.
_Avoid_: календарь, график

**Бронирование**:
Подтверждённая запись гостя на слот в рамках типа встречи.
_Avoid_: резерв, бронь; запись допустима для названия сценария, но не для сущности

**Страница записи**:
Публичная страница, где гость выбирает тип встречи и свободный слот, заполняет форму и подтверждает бронирование.
_Avoid_: лендинг, форма записи
