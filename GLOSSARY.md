# Календарь звонков

Учебный сервис онлайн-записи на встречи: владелец публикует типы встреч и расписание, гость выбирает свободный слот и бронирует звонок.

## Language

**Владелец**:
Единственный в первой итерации пользователь сервиса, который настраивает типы встреч и принимает бронирования.
_Avoid_: организатор, хост, пользователь

**Гость**:
Человек, который переходит по публичной ссылке и бронирует встречу.
_Avoid_: клиент, посетитель, пользователь

**Тип встречи**:
Шаблон встречи с названием, описанием и длительностью, на который гость может записаться.
_Avoid_: событие, услуга, звонок

**Архивный тип встречи**:
Тип встречи, скрытый из публичной записи; существующие бронирования сохраняются, новые не создаются.
_Avoid_: удалённый тип, неактивный тип

**Встреча**:
Запланированный звонок между владельцем и гостем.
_Avoid_: событие, ивент

**Предстоящая встреча**:
Встреча, интервал которой ещё не закончился, включая идущую сейчас.
_Avoid_: будущая встреча, текущая встреча

**Слот**:
Конкретный промежуток времени, доступный для бронирования.
_Avoid_: окно, таймслот, время

**Занятость**:
Свойство слота, при котором его интервал пересекается с интервалом существующей встречи; примыкание занятостью не является.
_Avoid_: блокировка, резерв

**Конфликт слота**:
Попытка забронировать занятый слот, завершающаяся отказом без создания бронирования.
_Avoid_: ошибка, гонка

**Расписание**:
Набор правил владельца, определяющий доступные для бронирования слоты.
_Avoid_: календарь, график

**Рабочие часы**:
Регулярный интервал, в котором владелец принимает встречи; в первой итерации — Пн–Пт 09:00–18:00 Europe/Moscow.
_Avoid_: график, окно

**Окно записи**:
Скользящий период из 14 календарных дней, начиная с текущей даты в Europe/Moscow, в котором гость может выбрать слот.
_Avoid_: горизонт, период

**Доступность**:
Набор свободных слотов в окне записи для выбранного типа встречи.
_Avoid_: расписание, свободное время

**Бронирование**:
Подтверждённая запись гостя на слот в рамках типа встречи.
_Avoid_: резерв, бронь; запись допустима для названия сценария, но не для сущности

**Страница записи**:
Публичная страница, где гость выбирает тип встречи и свободный слот, заполняет форму и подтверждает бронирование.
_Avoid_: лендинг, форма записи
